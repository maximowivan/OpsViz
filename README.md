# OpsViz — схема потоков операций

Визуализация и разбор операций перекачки (InduSoft I-OMS): схема потоков массы,
таблицы 1в1 как Excel, поиск, фильтры, пометки, выгрузка из базы и из Excel.

## Запуск без сборки (portable)

Папка `01-portable` в раздаче: `OpsViz.exe` + `ExcelDataReader.dll` + `OpsViz.exe.config`.
Установка не нужна. Требование: **.NET Framework 4.8** (входит в Windows 10 1903+).

Проверка версии: заголовок окна `Схема потоков операций v1.1.xxxx.xxxxx`.

## Сборка

- Visual Studio 2015+ (проект формата VS2015, `ToolsVersion 14.0`), **.NET Framework 4.8 Developer Pack**.
- Без NuGet и интернета: единственная зависимость `ExcelDataReader.dll` лежит в `libs/`.
- `OpsViz.sln` → Build Release/AnyCPU.

## Источники данных

1. **«Обновить из базы»** — прямой SQL в `iomsdb.oms.Transfer` (тот же запрос, что кнопка
   «Операции» в Excel). Строка подключения — один раз в диалоге, хранится в
   `%AppData%\OpsViz\sql.txt`. Только `SELECT`, базу изменить не может.
2. **«Открыть файл…»** — архивная Excel-выгрузка, лист «Операции». Источник всегда
   виден в статусбаре.

Подробности для пользователя — в `01-portable/README.txt`.
Подробности для работы — в `ИНСТРУКЦИЯ.txt` рядом с этой папкой.
